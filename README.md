# The-Escapists-Tileset-Randomizer

--------------------------------------------------
Randomizes the tile order of The Escapists tileset.
The output is always the same size as the input.

HOW TO USE
--------------------------------------------------
1. Double-click TE1 TILESET RANDOMIZER.exe
2. Click "Load Tileset"
3. Click "Randomize"
4. Click "Save"

THE RANDOMIZER ONLY WORKS WITH TE1 TILESETS!

Works on Windows 10/11.

-Everything was coded using C++-
